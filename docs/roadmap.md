# Product roadmap

Phase 1 is the only implemented phase: bid project creation, bulk tender upload, repository metadata, duplicate/revision foundations, RBAC and audit foundations.

1. **Phase 2:** approved-provider document classification and requirement extraction.
2. **Phase 3:** Missing Input / Estimation Readiness Engine.
3. **Phase 4:** department workflow and responsibility allocation.
4. **Phase 5:** employer-format generation and controlled bid preparation.
5. **Phase 6:** Primavera P6 upload, validation, and schedule outputs.
6. **Phase 7:** historical L1/L2/L3/L4 and win/loss intelligence.
7. **Phase 8:** bid-versus-actual execution learning.
8. **Phase 9:** advanced bid-decision intelligence and analytics.

Each phase must pass privacy, model-risk, security, data-residency and human-review gates. AI will work behind structured operational workflows, not replace them with a generic chat interface.
